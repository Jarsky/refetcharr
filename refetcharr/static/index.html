    File sizes

    Drag the markers, like Radarr's quality sizes. Sizes are MB per minute of runtime, so long films get more room. Above Maximum a film counts as oversized, a replacement must be at least Minimum, Preferred is what a good one comes in at, and below Too small an x265 file is flagged.

    Ratings

    The thresholds that rate a file LOW, MEDIUM or HIGH. The picture is rated for its resolution, in x265 terms: the audio's share is taken off the file size first, and other codecs are converted with the factors below (x264 needs about 1.5× the bitrate of x265 for the same picture). Ratings show in the lists and each film's details, and the least a replacement may have is set below.

    Radarr setup

    What Refetcharr relies on in Radarr. Mostly it stops Radarr upgrading replaced films straight back to remuxes, and the webhook tells Refetcharr about new files as they arrive. Fixes change Radarr only when you press them.

    Timings

    How long Refetcharr waits on Radarr and qBittorrent before it decides something. The defaults suit most setups.

    Sign-in

    One login protects the web UI and the API. Changing it signs out every other browser. Locked out? In the container: refetcharr login set <username>.

    API key

    For scripts and other apps: send it as the X-Api-Key header. The terminal UI and the refetcharr commands in the container use it by themselves, and Radarr's webhook carries it in its address (a new key needs the webhook fixed again under Radarr).

    Rescan the library?

    This reads every film from Radarr and rebuilds the oversized list and reports. It can take some time, and Radarr may be slower while it runs. Downloads carry on as normal.
